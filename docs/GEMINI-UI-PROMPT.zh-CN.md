# 给 Gemini 的 UI 优化任务（2026-10-01）

请先阅读仓库根目录 GEMINI-UI-HANDOFF.md，再对现有 React + TypeScript + Vite 项目做 UI 优化。

这是拼豆图纸软件 Stellabean，不是营销模板。要求基于现有代码修改，而不是创建不连接真实数据的静态演示。优先解决手机画板空间、按钮和工具栏密度、参考窗口、参数面板、弹窗和导航的一致性。保留图标，避免巨大卡片、过多留白和遮挡画板的浮窗。

## 功能不能丢

- 产品首页导航、开始创作、进入工作台、作品和公告入口。
- 图片上传、转换模式、尺寸、色板、背景移除、原图参考。
- 原图叠影及其透明度（状态和 setter 不能漏传），叠影缩放、平移和比例适配。
- 绘制、拖动、缩放、撤销、重做、保存、导出、统计和图库。
- 登录、积分报价、确认完成/解锁，以及管理员入口。
- 所有现有回调、props、权限门禁和错误状态。

## 禁止修改

不要修改图像算法、照片/Logo/卡通量化、黑色描边规则、色板数据、积分规则、API、后端、数据库、部署配置和立体拼豆模块。GridCanvas 中只改 UI 布局，不重写画布数学、渲染层级或手势事件。

## 交付

1. 最好交付修改后的源文件或相对于本次基线的 Git patch；保留原目录路径，不只给截图。
2. 提供 GEMINI-UI-RESULT.md：改动清单、理由、测试结果、桌面/手机截图、已知问题。
3. 验证 360/390px 手机宽度、手机横屏、768px、1280/1440px 桌面，不出现按钮重叠和横向溢出。
4. 执行 TypeScript、Vitest、Vite build、git diff --check；不要为了通过测试删掉业务断言。
5. 不提交、不部署、不覆盖当前项目的算法或后端文件。

用户会把交付物放到 D:/Build_Apps/gemini-ui-return/。Codex 之后先检查和本地整合 UI，再单独优化算法并根据用户授权提交部署。若 Gemini 可直接读取本仓库，也应先在副本里操作，避免同时修改工作区。
