### 000f. 识别流程新增「最大颜色数」限制（2026-11-25）
> 用户需求：导入识别时可以限制整张图最多用多少种颜色（色板 221 色全开时，成品买料/配色都难）。

**实现（识别管线后处理，`src/utils/importRecognition.ts`）**
- 新选项 `maxColors`（0 = 不限，默认）：识别/refine 链照常在全色板上跑完，之后若用色超限 → 按**出现格数**保留前 N 支（并列按 id 字典序，结果稳定），其余格**用各自 sampleRgb（面积加权代表色）在保留色板里重新选色**——不是"被删色号→最近保留色号"的色板级映射，同一支被删色在不同光照下可归到不同保留色，保住格子本身的颜色信息。

- **两个键位坑（都实测踩过）**：`cell.colorId` 是色板的 `color.id`（如 MARD-xx）**不是 code**（A1）——保留集按 code 建会让过滤永远为空、限制**静默失效**（distinct 纹丝不动、无报错）；重选写回时 colorId 也必须写 id，混用两套键会让 summary.distinctColors 直接翻倍（8 → 16）。测试刻意让 id ≠ code 锁住该契约（`importRecognition.maxColors.test.ts`）。

- 验证：street-boy 全图 124 色 → max8=8 色（10149 格重映射）、max24=24 色（4030 格）；全量 179 files / 1914 tests 通过；未启用时函数直接返回 null，识别结果逐位不变（零回归面）。

  3. **单位字尾裁**（`CARD_UNIT_GAP=6`，竖排路径）：数字间间隙实测 0-4px、数字↔粒 8-12px，按最后一个 ≥6px 间隙切掉尾部单位组（高度守卫：单位字至少与数字同高）。亚像素版下多数行已由宽块丢弃兜住，此规则是兜底。
  4. **横排数量区 run 裁剪**（`trimCountRuns`，`CARD_COUNT_RUN_GAP=10`）：色块内印码残片（"H2" 的 '2'）隔着票缘空白被并进数量区，位宽再像数字也不是数量——按词间距切 run 取最长（并列取最右）。
  5. **横排字形重采样**（`sharpenCountBitmaps`）：card1 的数字是粗体深墨，小字号下 CONTRAST=60 的 mask 把笔画和字腔一起吃成实心团（计数模板 '0' 是个几乎实心的圆），于是 '5'/'9' 全被判成 '0'（255→200、197→107、45→40）。**切分用厚 mask 做几何、识别用「只留强墨」的细 mask（对比 150 双线性）做形状**，bbox 不变、切分零扰动。**card1 数量 40→51/62（判分口径 29→37/43）**。守卫：强墨 <5% 或 >90%（实心块/白字印色票）保留原位图 → card2 零回归。
- **证伪记录（重要，别再走）**：①`GlyphShapePrior`（字宽先验 aspect=0.18 / 孔洞先验 hole=0.12）实测**负收益**——card3 45→31，根因=计数模板是**聚类平均位图**，孔洞在平均时被抹平（'8' 模板只剩 1 孔），按模板孔洞罚等于罚真字形。参数已留 dormant（权重 0），要用得先把模板改成「簇中位实例」。②把亚像素二值化全局打开：card1 40→32（粗笔画糊连成宽块，切片回收退化）——必须按版式分流。

### 00. 图例「白色票面条目丢失」修复：dog-girl 54→60/62 条（2026-11-24 深夜场）
- **现象**：框选整条图例解析出 **54 条**，但图上实际有 **62 个条目**（比真值少 8 条，后续条目整体错位）。

## 二、注意事项（坑清单，按疼的程度排）

1. **部署必须先 build**：`wrangler pages deploy` 传的是 `dist/`，不自动构建。漏 build = "改了代码线上没变化"。
2. **全量 vitest 并发跑会假失败**（多 Chrome 抢资源，importLegend 计时敏感测试被饿死）——用 `npm run verify`（串行 `--no-file-parallelism`）或单跑可疑文件。
3. **基准回归必须用浏览器判分**（`node scripts/browser-card-test.mjs`）：数量识别依赖 DOM canvas，Node 里跑数量全是 0。
4. **sed 批量改源码后必须 grep 核验**——锚点不匹配会静默失败（已发生多次）。
5. ** vite ssrLoadModule/浏览器 evaluate 的模块坑**：page.evaluate 里 `import('react')` 裸说明符解析失败，必须经 vite 管道加载项目内文件；验证页加载真实 App 时 querySelector 会匹配到 App 元素，fixture 选择器必须限定 `#fixture-host` 作用域。
6. **布局**：CSS Grid 在 flex-1 固定高容器里默认 `align-content: stretch` 拉伸行——筛选型网格必须 `content-start`；grid 子项 `min-width:auto` 不收缩，手机溢出真凶通常是它。
7. **重写 CSS 必须整段浏览器截图复核**（丢一个 display:flex 就会竖排堆叠）。
8. **印刷票色≠豆色是物理上限**（card1 先验命中仅 33%）——先验只用于窗口约束和 ΔE≤6 的码长辅助切片。
9. **求解层禁止全局重解**：唯一性名额是全局耦合，局部翻案会连锁打翻无关行（历史教训 #1/#29/#57）。
10. **诊断脚本命名 `tmp-*`** 已进 .gitignore，不会污染 git status；但别把有长期价值的脚本叫 tmp-*。
